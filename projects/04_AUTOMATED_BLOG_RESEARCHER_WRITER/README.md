# 📝 Automated Blog Post Researcher & Writer (Multi-Agent StateGraph Pipeline)

An enterprise-grade Multi-Agent Blog Generation & Verification Pipeline built with **LangGraph**, **Tavily** and **Google Gemini (gemini-3.6-flash)**.

Demonstrates **role specialization**, **deterministic state sharing across workflow boundaries**, **real-time web-grounded research**, and an **automated fact-checking & editor revision loop**.

---

## 🏗️ Architecture

```
                      ┌──────────────────────────────┐
                      │        START (Topic)         │
                      └──────────────┬───────────────┘
                                     │
                                     ▼
                      ┌──────────────────────────────┐
                      │     1. RESEARCHER AGENT      │  (Tavily Web Search + Facts Extraction)
                      └──────────────┬───────────────┘
                                     │ Passes Research Notes & Sources
                                     ▼
                      ┌──────────────────────────────┐
                      │       2. WRITER AGENT        │  (Synthesizes Structured Markdown Blog Post)
                      └──────────────┬───────────────┘
                                     │ Passes Draft
                                     ▼
                      ┌──────────────────────────────┐
                      │    3. FACT-CHECKER AGENT     │  (Audits draft claims against research notes)
                      └──────────────┬───────────────┘
                                     │ Conditional Routing: should_revise()
                   ┌─────────────────┴─────────────────┐
                   │                                   │
         [fact_check_passed == False                   [fact_check_passed == True
          and revision_count < 2]                       or max_revisions reached]
                   │                                   │
                   ▼                                   ▼
     ┌───────────────────────────┐       ┌───────────────────────────┐
     │      4. EDITOR AGENT      │       │            END            │
     │  (Revises unverified      │       │   (Final Published Post)  │
     │   claims & polishes draft)│       └───────────────────────────┘
     └─────────────┬─────────────┘
                   │
                   └───────────► Loop to END
```

---

## 🔑 Shared State Schema (`BlogState`)

State is passed deterministically across all nodes using a typed `BlogState` schema:

```python
class BlogState(TypedDict):
    topic: str                     # Target blog topic
    research_notes: str            # Fact-checked bulleted notes from Tavily
    sources: List[str]             # List of reference URLs
    draft: str                     # Initial draft generated by Writer Agent
    fact_check_passed: bool        # Validation status from Fact-Checker Agent
    fact_check_feedback: str       # Detailed critique / unverified claims report
    final_post: str                # Final published markdown blog post
    revision_count: int            # Active revision count (max 2)
```

---

## ⚡ Key Features & Node Specialization

1. **Researcher Agent (`research_node`)**:
   - Executes live web search queries via `TavilySearch`.
   - Extracts structured, bulleted key findings, statistical metrics, and source URLs.
2. **Writer Agent (`writer_node`)**:
   - Synthesizes technical insights into an engaging, structured Markdown article (H1 Title, Introduction, Core H2/H3 Sections, Conclusion, References).
   - Generates explicit inline source citations `[Source](url)`.
3. **Fact-Checker Agent (`fact_checker_node`)**:
   - Uses Pydantic structured output (`FactCheckReport`) to audit the draft against raw research notes.
   - Flags ungrounded claims or hallucinated assertions.
4. **Editor Agent (`editor_node`)**:
   - Polishes draft quality and corrects any flagged claims based on fact-checker feedback.
5. **Conditional Control Loop (`should_revise`)**:
   - Automatically routes unverified drafts to the Editor Agent (up to `max_revisions = 2`) to ensure production reliability without infinite execution.

## 💻 Setup & Running

1. Install dependencies: `uv sync`
2. Add `.env` in the project root:
```env
GOOGLE_API_KEY=your_google_gemini_api_key_here
TAVILY_API_KEY=your_tavily_api_key_here
```
3. Open `app.ipynb` in `projects/04_AUTOMATED_BLOG_RESEARCHER_WRITER/` and run all cells top-to-bottom using the `.venv` kernel.
