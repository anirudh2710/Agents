# 📝 Automated Blog Post Researcher & Writer (Generator-Evaluator Reflection Architecture)

An enterprise-grade Multi-Agent Blog Generation & Verification Pipeline built with **LangGraph**, **Tavily**, and **Groq (Llama 3.3 70B)**.

Demonstrates **role specialization**, **deterministic state sharing across workflow boundaries**, **real-time web-grounded research**, **3-Node Generator-Evaluator (Reflection) Architecture**, and **Status Tracking & Audit Disclaimers**.

---

## 🏗️ Architecture (Reflection Pattern + Audit Fallback)

```
                  ┌──────────────────────────────┐
                  │       1. RESEARCHER AGENT     │  (Tavily Web Search)
                  └──────────────┬───────────────┘
                                 │
                                 ▼
                  ┌──────────────┴───────────────┐
                  │                           ◄──┐
                  ▼                              │
   ┌──────────────────────────────┐              │
   │   2. WRITER AGENT (DUAL-MODE)│              │  Revision Reflection Loop
   └──────────────┬───────────────┘              │  (passes feedback & draft)
                  │ Passes Draft                 │
                  ▼                              │
   ┌──────────────────────────────┐              │
   │    3. FACT-CHECKER AGENT     │              │
   └──────────────┬───────────────┘              │
                  │ Conditional Edge             │
┌─────────────────┴─────────────────┐            │
│                                   │            │
[fact_check_passed == False         [fact_check_passed == True
 and revision_count < 2]             or max_revisions reached]
│                                   │
│ (Route to Writer)                 │ (Route to END)
└───────────────────────────────────┼───────────► END
                                    │
                  [If max_revisions reached with errors:
                   Assign status = 'PUBLISHED_WITH_DISCLAIMER'
                   & append audit disclaimer note]
```

## 🔑 Shared State Schema (`BlogState`)

State is passed deterministically across all nodes using a typed `BlogState` schema:

```python
class BlogState(TypedDict):
    topic: str                     # Target blog topic
    research_notes: str            # Fact-checked bulleted notes from Tavily
    sources: List[str]             # List of reference URLs
    draft: str                     # Current draft generated by Writer Agent
    fact_check_passed: bool        # Validation status from Fact-Checker Agent
    fact_check_feedback: str       # Detailed critique / unverified claims report
    status: str                    # "VERIFIED_AND_APPROVED", "REQUIRES_REVISION", or "PUBLISHED_WITH_DISCLAIMER"
    final_post: str                # Final published markdown blog post (with disclaimer if max revisions hit)
    revision_count: int            # Active revision count (max 2)
```

---

## ⚡ Key Features & Status Classifications

1. **Researcher Agent (`research_node`)**:
   - Executes live web search queries via `TavilySearch`.
   - Extracts structured, bulleted key findings, statistical metrics, and source URLs.
2. **Writer Agent (`writer_node` - Dual-Mode Generator)**:
   - **Initial Mode** (when `fact_check_feedback` is empty): Synthesizes research notes into a structured Markdown article with inline citations `[Source](url)`.
   - **Revision Mode** (when `fact_check_feedback` is present): Rewrites the existing draft to fix unverified claims flagged by the fact-checker.
3. **Fact-Checker Agent (`fact_checker_node` - Evaluator & Status Classifier)**:
   - Uses Pydantic structured output (`FactCheckReport`) to audit the draft against raw research notes.
   - Classifies state into **3 Status Modes**:
     - `VERIFIED_AND_APPROVED`: Draft passed 100% fact-checking audit.
     - `REQUIRES_REVISION`: Draft has unverified claims; routed to Writer.
     - `PUBLISHED_WITH_DISCLAIMER`: Max revisions ($N=2$) reached with remaining unverified claims; delivers latest draft with an appended editorial disclaimer.
4. **Direct Reflection Revision Loop (`should_revise`)**:
   - Routes `fact_checker` ──► `writer` directly whenever ungrounded claims are detected (up to `max_revisions = 2`).

## 💻 Setup & Running

1. Install dependencies: `uv sync`
2. Add `.env` in the project root:
```env
GROQ_API_KEY=your_groq_api_key_here
TAVILY_API_KEY=your_tavily_api_key_here
```
3. Open `app.ipynb` in `projects/04_AUTOMATED_BLOG_RESEARCHER_WRITER/` and run all cells top-to-bottom using the `.venv` kernel.
